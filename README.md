# Aavedan Saathi

Free, ad-free helper tools for Indian exam and job application forms: photo/signature resizer with official sizes, an SSC-rule Hindi (Krutidev/Unicode) and English typing test, and a Krutidev <-> Unicode converter. Everything runs in the browser.

Live: https://shivamkole1969.github.io/aavedan-saathi/

Not a government website.
